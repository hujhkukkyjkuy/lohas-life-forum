# 康城生活圈 · Lohas Life

Hyperlocal lifestyle forum MVP for **LOHAS Park / 日出康城** residents.

- Live (GitHub Pages): https://hujhkukkyjkuy.github.io/lohas-life-forum/
- Stack: Vite + React + TypeScript (static)
- Docs: `PRODUCT.md`, `MONETIZATION.md`, `docs/OPS_PLAYBOOK.md`, `docs/VIDEO_PLAYBOOK.md`

## Dev

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

`base` is set to `/lohas-life-forum/` for GitHub Pages. Routing uses `HashRouter`.
