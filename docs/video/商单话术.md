# 商单话术 · 本地店短视频植入（互补论坛试投）

> 给人：建峰 WhatsApp／面谈本地 Cafe、甜品、补习、诊所资讯位等。  
> 原则：**赚钱** + **诚实流量**；短视频套餐与论坛试投可捆可分。  
> 价目对齐站点 `#/rates` 与 `MONETIZATION.md`（示范 · 可议）。

---

## 1. 开场（15 秒口述）

「你好，我係康城生活圈站长。我哋系面向日出康城住户嘅**公开生活网页**——唔似 Facebook／Telegram 群成日禁广告、要审批、又难搜。  
而家冷启动，累计访客大约二十以内，所以试投价可以议、可以五折，不满意可停。我想搵三几间本地店做**真实案例**。」

## 2. 产品组合（点样卖）

| 组合 | 包含 | 开口价（示范） | 适合 |
|------|------|----------------|------|
| A 论坛试投 | 信息流合作卡 7 日 **或** 置顶 7 日 | HK$800 起／置顶 HK$1,200 起 | 只想网页曝光 |
| B 短视频单条 | 15–45 秒口播＋多平台发布（约定平台） | **由 HK$1,500** | 要镜头口碑 |
| C 试投＋短视频 | A + B（同周曝光） | 可打包议价 | 要案例完整 |
| D 月费露出 | 商户 Tab 精选 30 日 | HK$2,000–6,000 | 试投满意后续约 |

短视频规格（讲清楚）：
- 粤语口播、45 秒内成品常见；可按店加「推广」标  
- 画面：自拍口播 + 店家提供／现场授权空镜（**唔用**盗版影视剪辑）  
- 发布：论坛短视频帖 + 约定嘅抖音／小红书／IG 等  
- 交付：脚本确认 → 成片 → 发布链接／截图

## 3. WhatsApp 短讯模板（可复制）

### 3.1 首次接触
```
你好，我係「康城生活圈」站长（日出康城公开生活网页）。
Facebook／TG 群好多时禁广告、要审批；我哋有公开费率页，欢迎本地店试投。
诚实讲：而家累计访客约二十以内（冷启动）。首周可议／可 5 折，不满意可停。
想唔想睇下费率同合作页？
费率：https://hujhkukkyjkuy.github.io/lohas-life-forum/#/rates
合作：https://hujhkukkyjkuy.github.io/lohas-life-forum/?notrack=1#/coop
```

### 3.2 推短视频植入
```
除咗论坛曝光，我可以帮你拍一条 15–45 秒粤语口播短视频（街坊视角，标「推广」），
发去约定平台 + 论坛。短视频商户套餐由 HK$1,500 起，可同「试投一周」打包。
你提供：店名、一句卖点、2–3 张授权相片或约拍时段。
我提供：脚本、口播、字幕、发布同截图证言。
```

### 3.3 异议「你流量咁少做咩」
```
正正因为早期，价可以低、档期灵活，换你一个真实案例同截图。
你得到：公开链接可转发、费率透明、唔使等群 admin 批广告。
唔满意七日内可以停——我宁願诚实，唔会扮过万访客。
```

### 3.4 收口约档
```
可唔可以本周定：① 信息流或置顶试投；② 要唔要加一条短视频。
你回我卖点同联系人，我发简单确认（项目、价、日期、标推广）。
转数／收款方式面谈时讲清楚。WhatsApp 本线：+852 4436 1681
```

## 4. 面谈／电话要点清单

1. 先讲 **差异**：公开网页 vs 禁广告封闭群  
2. 主动讲 **访客约二十以内**（建立信任）  
3. 给链接：`#/rates` `#/coop` `#/why-us`  
4. 推冷启动首选：**信息流 HK$800 起** 或 **置顶**；有镜头需求再加短视频  
5. 确认是否标「推广／赞助」  
6. 录：店名、卖点、禁讲内容（医疗勿疗效）、发布时间、平台名单  
7. 收钱／档期书面确认（WhatsApp 摘要即可）

## 5. 短视频植入脚本骨架（商单版）

```

（卖点 20 秒）佢哋强项系… 适合… 我亲测／探店感受系…
（信息 15 秒）地址／楼层／大概价位／营业提示（店家提供）。
（合规）本条为推广合作。
（CTA）想睇更多本地店同街坊帖——康城生活圈，链接喺简介；
亦欢迎其他商户睇费率页试投。
```

**影评类商单：** 只口播观感 + 合法预告／自拍；**禁止**热播剧集正片切片。
