# 平台改写清单 · 一稿多平台

> 同一条口播／成片，按平台改 **标题、封面、话题、置顶评论**。  
> 口播正文可共用；禁忌见 `00-概述.md`。

---

## 总原则

| 项 | 做法 |
|----|------|
| 成片比例 | 一律 9:16 |
| 口播 | 粤语繁中为主；英文字幕可选（Shorts／Reels） |
| CTA | 每平台只强推 **一个** 动作（开链接／留评论） |
| 链接 | 抖音／部分平台外链受限 → **评论置顶 + 主页简介** 双保险 |
| 标签数量 | 主标签 4–8 个；堆砌无意义 tag 少用 |
| 合规 | 商单标「推广」；医疗加「非医疗建议」；诚实流量唔虚报 |

**论坛主链（发布时贴）：**  
`https://hujhkukkyjkuy.github.io/lohas-life-forum/`  
合作／费率：`#/coop` · `#/rates`

## 1. 抖音

| 元素 | 改法 |
|------|------|
| 标题 | 口语＋数字／反问；≤30 字；前 12 字出利益点 |
| 封面 | 大字 8 字内（如「康城站方便？」）；人脸＋场景 |
| 话题 | `#日出康城` `#将军澳` `#香港生活` + 主题词 |
| 置顶评论 | 论坛链接 + 一句「公开网页唔使入群」 |
| 注意 | 外链能力看账号；导流靠评论／主页 |

**标题转化例（Day1）：**  
「康城站出入到底方唔方便？街坊实测 60 秒」

---

## 2. 小红书

| 元素 | 改法 |
|------|------|
| 标题 | 功效／清单感；可用｜分隔；加地域词 |
| 封面 | 偏「笔记感」：步骤数字、前后对比字 |
| 正文 | 口播要点改成 3–5 条 bullet + emoji 适度 |
| 话题 | `#日出康城` `#LOHASPark` `#香港探店` 等 |
| 置顶 | 链接＋「康城生活圈」搜索引导 |

**标题转化例（Day3）：**  
「The LOHAS 冷气太干｜润唇＋护肤随身清单」

---

## 3. B站（短视频／动态视频）

| 元素 | 改法 |
|------|------|
| 标题 | 可稍信息增量；加「测评／口播／教学」 |
| 封面 | 左右分镜或大字＋地标 |
| 分区 | 生活／美食／亲子按题材 |
| 简介 | 贴完整论坛链接 + 标签 |
| 话题 | 少而准；可加「港岛东」「将军澳」 |

**标题转化例（Day5）：**  
「本地论坛用法｜日出康城「今日問題」教学口播」

---

## 4. YouTube Shorts

| 元素 | 改法 |
|------|------|
| 标题 | 可中英混合；SEO 词：LOHAS Park / Tseung Kwan O |
| 描述 | 英文 1–2 句摘要 + 繁中 CTA + 完整 URL |
| 字幕 | 建议烧录繁中；可选英文字幕轨 |
| Hashtag | `#Shorts` `#LOHASPark` `#HongKong` `#TseungKwanO` |

**标题转化例（Day2）：**  
「LOHAS waterfront sunset walk — 60s local tip」

---

## 5. Facebook · Instagram Reels

| 元素 | 改法 |
|------|------|
| 标题／文案 | FB 可较长故事感；IG 首句钩子＋换行 |
| 封面 | IG 更重脸部＋大字；FB 可放链接预览到论坛 |
| 话题 | IG 用 5–10 个；FB 可少 tag、多重内容 |
| 链接 | FB 帖可直接贴论坛 URL；IG 用 bio／Stories 链接／评论 |
| 社群 | 可分享到相关本地 group（遵守群规，商单先问 admin） |

**文案转化例（Day6）：**  
「Cafe／补习／诊所：封闭群禁广告嘅话，公开生活圈试投下？诚实讲而家流量仲好早期——」
