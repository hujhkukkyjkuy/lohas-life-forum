# 康城生活圈 · 每周运营手册（给建峰／新手）

> 用繁体、口语写。你唔使识写 code，跟住做就得。  
> 目标：论坛先做好；「易租」而家暂停，迟啲先桥接。

---

## 0. 你系边个角色？

你係 **社区运营**：每周发布内容、回覆邻居留言、约本地商户试投放。  
技术／改网站：有工程师或 AI 助手帮手；呢份文件教你 **内容同生意节奏**。

**永远记住**
1. 唔好改 `yizu.grok.me`（易租暂停中）  
2. 医疗帖只可以「资讯／经验」，唔可以扮医生  
3. 广告要标「推广／赞助／Demo」

## 1. 第一次上线（只做一次）

### 步骤
1. 用手机打开论坛预览网址（GitHub Pages 那个）。  
2. 检查：首页有帖、分类可以撳、商户页有价目、「发帖」可以本地试。  
3. 把网址存书签；发给 3–5 个康城朋友试玩，问：「你会唔会每周睇？」  
4. 建一个笔记（Notion／备忘录）叫「康城生活圈运营」，复制本手册目录。

### 准备物料夹（电脑或云端）
```
康城生活圈/
  本周帖子草稿/
  短视频口播/
  商户名片照片/
  已发布记录.xlsx（日期、标题、分类、互动）
```

## 2. 每周固定节奏（建议）

| 日子 | 你要做咩 | 大约时间 |
|------|----------|----------|
| 周一 | 定本周 3–5 个题目；拣 1 条短视频主题 | 30 分钟 |
| 周二 | 写／改 2 篇帖（可用 AI 起稿，你亲自改地名同语气） | 45 分钟 |
| 周三 | 发 1 篇 + 回覆留言；联络 1 个商户 | 40 分钟 |
| 周四 | 按 `VIDEO_PLAYBOOK.md` 做／发出 1 条短视频 | 60 分钟 |
| 周五 | 发饮食或海旁轻松帖；整理商户意向 | 30 分钟 |
| 周末 | 自己去海旁／商场「实地感受」；拍参考相片（唔好偷拍人面） | 随意 |

**最低配（好忙嗰周）**：发 **2 篇文字帖 + 1 条短视频**，仍然好过断更。

## 4. 变现阶段 A／B／C（跟住升级）

### 阶段 A · 冷启动（第 1–6 周）
**目标**：有稳定内容；有 1–2 个「示范商户案例」（甚至免费／半价）。

你要做：
1. 每周保底发帖（见上表）。  
2. 印／发电子版「商户一页纸」：置顶 7 天示范价（见 `MONETIZATION.md`）。  
3. 亲自走访 The LOHAS 2–3 间店：Cafe、补习、诊所接待处，话：「我哋做康城住户论坛，想俾你试投放。」  
4. 成交前用 Demo 位展示「置顶推广」长什么样。

**成功标准**：连续 4 周有发文；至少 1 个商户口头答应试。

### 阶段 B · 有人睇（大约有固定回头客）
**目标**：原生广告 + 短视频套餐开始收钱。

你要做：
1. 把价目定实（可仍写「试业价」）。  
2. 每周最少 1 条商户相关短视频或赞助卡。  
3. 记录：边类帖赞好／留言最多（以后多写嗰类）。  
4. 试办 1 次「海旁市集／周末活动」赞助卡。

**成功标准**：单月广告／置顶收入能覆盖你支出嘅小额工具费。

### 阶段 C · 信任建立后再扩
**目标**：团购／票务分销；**先论坛、后租赁**。

你要做：
1. 团购先做「意向搜集帖」，真收款用正规方式（自己或合作平台）。  
2. 「易租」若将来恢复：只在「我的／生活」放轻量入口，例如「租务资讯稍后接入」，**唔好**而家深链去暂停站。  
3. 代理／业主 Freemium：等论坛有信任再谈分润，避免一上来好似地产广告板。

**原则：Forum first（论坛先）→ 有社区温度 → 先变现本地生活 → 最后先桥易租。**

## 5. 商户沟通「开口稿」（可照读）

> 「你好，我係做『康城生活圈』——专服务日出康城住户嘅生活论坛。  
> 而家有置顶同信息流推广位，示范价大概一千几至几千港币一周／一个月，看套餐。  
> 想唔想试七天？我可以帮你写成住户喜欢睇嘅帖，并标示推广。」

若对方问医疗广告：  
> 「我哋只接受诊所『位置／预约方式』资讯展示，唔会帮你写疗效保证。」

## 9. 出问题点算？

- **网站打不开**：找技术帮手睇 GitHub Pages；你先用已发帖备份继续写稿。  
- **有人骂战**：锁帖／删人身攻击（上线审核后）；而家 MVP 可先喺留言约定礼貌。  
- **商户要疗效文案**：拒绝；改推「预约资讯 + 位置」。

## 10. 一句话总结

**每周：写帖 → 拍／生成短视频 → 回覆邻居 → 约一个商户。  
钱：A 试投放 → B 短视频套餐 → C 团购再谈易租。  
心法：论坛先，租赁后。**
